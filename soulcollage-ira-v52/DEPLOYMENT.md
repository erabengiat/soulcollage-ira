## 🎯 3 צעדים בלבד | 3 Steps Only

### **שלב 1: הוצא את ה-ZIP**
```
1. הוצא את הקובץ: soulcollage-ira-v52.zip
2. תיקייה חדשה בחרת: soulcollage-ira-v52/
3. כל הקבצים בתוכה
```

### **שלב 2: עדכן את הנתונים**
```
קובצים לעדכן ONLY:

1. data/data.json
   → החלף בשלך (עם כל קלפים)

2. images/
   → הנח את כל תמונות קלפים (1.jpg, 2.jpg, ...)
```

### **שלב 3: GitHub Push**
```bash
cd soulcollage-ira-v52/

# קד את כל הקבצים
git add .

# אישור עם הודעה
git commit -m "v52 update: timeline analysis, fullscreen, vivid colors"

# שלח לGitHub
git push origin main
```

**זהו! 🎉**
